## 0. Summary

- **Order:** S1 → **G1** → S2 → S6a → S6b → S3 → S5 → S4 → S7 → **G2** → S8.
  - PLAN.md:221 numbers the slices S1..S8. §5 below explains each change of order.
- **S1 is bigger than PLAN's one line.** It also brings:
  - the lifecycle skeleton (P4 deferral);
  - the 64 MiB allocator cap;
  - the curated library set;
  - `GENERIC_ERROR`;
  - the test and CI infrastructure on both OSes.

  **Your hours for S1: about 16–25 h (plan with 20 h). The G1 trip wire is 40 h.**
- **Native boundary:**
  - Two C compile units: `machine.c` (Lua, never `jni.h`) and `jni_machine.c` (JNI, never a Lua header). A Lua error therefore cannot cross a JVM frame, by construction.
  - Values cross as one `byte[]` per call, and Java does the dispatch.
  - No `JNI_OnLoad`, no `FindClass`, no global refs. The `cclj.c:16` rule "no mutable static state" stays as it is.
- **Lifecycle authority:** a Java monitor in `NativeMachine`. It is never held across a native resume, a native free, an upcall or a CC:T call. A C `busy` flag is the second line of defence.
- **Tests:**
  - Tier 0: C, no JVM.
  - Tier 1: `BridgeProbe`, JDK-only. It also runs in the natives CI jobs, so it covers Windows and glibc 2.28.
  - Tier 2: `MachineSpecs`, the CC:T machine contract, differential against Cobalt, plus one through-`Computer` case.
  - A scan fails any JVM task that prints checked-JNI output.
- **M1 total for you:** about 73–116 h, roughly 9–19 weeks at 6–8 h/week. That is inside PLAN §5.5's 57–175 h.

## 3. S1, implementation-ready

### 3.1 Goal

The PLAN's 3-line bios runs on LuaJIT through JNI:

```lua
term.write("hi")
local x = 1
error("boom")
```

It calls the real `TermAPI.write`. `handleEvent(null, null)` then returns `MachineResult.error("bios.lua:3: boom")`, the machine frees itself, and all of this runs clean under `-Xcheck:jni` on Windows x64 and Linux x64.

### 3.2 Scope

**In S1:**
- **State:** counting allocator with a 64 MiB per-computer cap (decision 8); curated libraries; `jit.security` check and `maxmcode=256` before `jit` is removed.
- **API tables:** one per API in `env.apis()`, built through `env.luaMethods().forEachMethod`, with each method bound to its own target. A non-null `getModuleName()` also goes into `_LOADED`.
- **Bios:** compiled as `@bios.lua` in mode `"t"` into a coroutine, and not run.
- **`handleEvent(null, null)`:** resumes the coroutine. YIELD → `OK`, return → `GENERIC_ERROR`, error → `error(msg)`.
- **Host calls with scalar values** (nil, boolean, number, Latin-1 string) in both directions, and `byte[]` results.
- **Errors:** `LuaException` levels are honoured; any other `Throwable` becomes `Java Exception Thrown: …` at level 0. Escaping error values are rendered raw, with no traceback.
- **Constructor:** a compile error or a binary chunk becomes `MachineException`, and so does every other constructor failure.
- **Lifecycle:**
  - `close()` is idempotent and may be called from any thread;
  - the free is deferred while a call runs;
  - `handleEvent` after `close()` throws `IllegalStateException`;
  - a machine closed while running reports `TIMEOUT`.
- **Infrastructure:** Tier 0/1/2 tests, the JNI scan, lint, the `CCLJ_DEBUG` build, CI on both OSes, and a load-once native holder with an ABI check.

**Out of S1:**

|---|---|---|

| Off-switch, contract probe | S8 | — |

### 3.3 Architecture

1. **Java dispatches; C only moves bytes.**
   - Each API method is a C closure, `api_call`. Its one upvalue is the function index (a number).
   - One upcall per host call: `byte[] NativeMachine.upcall(int fn, byte[] request)`.
   - C never references a CC:T class.
2. **The compile-unit split enforces the phase rule (DESIGN.md:143-149).**
   - `api_call` runs phase 1 (Lua → request buffer, may raise), then phase 2 (`cm_host_fn`, implemented in `jni_machine.c`, which cannot call Lua), then phase 3 (reply → Lua, may raise).
   - `natives/tests/lint-natives.sh` checks the include graph.
3. **Java owns the lifecycle.** The monitor `NativeMachine.lock` guards `handle`, `running` and `closed`. Whoever sets `handle = 0` under the lock frees the state, outside the lock. C adds an atomic `busy` flag.
4. **No JNI state survives a native call.**
   - `nResume` looks up `upcall` with `GetObjectClass` + `GetMethodID` once per event, on its own stack.
   - `JNIEnv*` and `self` live in a struct on `nResume`'s stack.
   - No `JNI_OnLoad`. (A planning spike used `PushLocalFrame` with no `JNI_OnLoad` under `-Xcheck:jni` and got no warnings.)
5. **The state is a strict subset of the final sandbox.** Libraries are opened one by one and dangerous ones are removed at once. Later slices only add.
6. **Every C function carries a run-context tag.**

   | Tag | Meaning |
   |---|---|
   | `UNPROTECTED` | non-raising calls only |
   | `PROTECTED` | a `lua_cpcall` body; may raise |
   | `LUA_CFUNCTION` | called by Lua; may raise in phases 1 and 3 only |
   | `NO_LUA` | `jni_machine.c` |

### 3.5 C API (`cclj_machine.h`)

```c
#define CCLJ_ABI 1                 /* NativeMachine.ABI must match; checked once after System.load */

#define CM_ST_OK        0          /* cm_load: bios compiled */
#define CM_ST_YIELD     1          /* -> MachineResult.OK; machine kept (S2: message = filter) */
#define CM_ST_RETURNED  2          /* -> GENERIC_ERROR; dead */
#define CM_ST_ERROR     3          /* uncaught error, OOM, load error -> error(msg) / MachineException; dead */
#define CM_ST_INTERNAL  4          /* misuse: busy, dead, bad handle, event in S1 -> internal error; dead */
/* S6a adds CM_ST_ABORTED 5 -> TIMEOUT */

#define CM_HOST_OK       0
#define CM_HOST_E_JNI    1         /* a JNI call failed (e.g. OutOfMemoryError); exception cleared */
#define CM_HOST_E_JAVA   2         /* the upcall threw; ExceptionDescribe (prints and clears) */
#define CM_HOST_E_NULL   3         /* the upcall returned null */
#define CM_HOST_E_TOOBIG 4         /* reply > CM_WIRE_MAX */
#define CM_HOST_E_NOMEM  5         /* reply buffer could not grow */

#define CM_WIRE_MAX (16u << 20)    /* max request/reply/spec/bios bytes (S3 revisits) */
#define CM_MSG_MAX  (64u << 10)    /* error/filter text is cut to this (DESIGN.md:219) */

typedef struct cm_machine cm_machine;
typedef struct cm_buf { unsigned char *data; size_t len, cap; } cm_buf;   /* malloc; owned by the machine */

/* NO_LUA. Called only from api_call phase 2. Writes the reply into *rep. */
typedef int (*cm_host_fn)(void *host, uint32_t fn, const cm_buf *req, cm_buf *rep);

cm_machine *cm_new(size_t mem_limit, uint64_t id_key);           /* UNPROTECTED; NULL = out of memory */
int  cm_load(cm_machine *m, const unsigned char *spec, size_t spec_len,
             const unsigned char *bios, size_t bios_len);          /* CM_ST_OK | CM_ST_ERROR | CM_ST_INTERNAL */
int  cm_resume(cm_machine *m, cm_host_fn fn, void *host,
               const unsigned char *event, size_t event_len);      /* S1: event must be NULL */
const unsigned char *cm_message(const cm_machine *m, size_t *len); /* last error/filter; valid until next cm_* call */

```

`struct cm_machine` is private to `machine.c`:

```c
struct cm_machine {
  unsigned char pad0[64];    /* calloc only guarantees 16-byte alignment, so intr_req has 64 bytes of padding */
  uint32_t intr_req;         /* on each side to own its cache line. S6a: written by other threads. Unused in S1 */
  unsigned char pad1[60];
  uint32_t magic;            /* CM_MAGIC live, CM_DEAD after free: a test tripwire, not a defence */

  int state;                 /* CM_NEW, CM_SUSPENDED, CM_DEAD: the bios coroutine (F4) */
  lua_State *L;              /* main thread: runs only our cpcall bodies, never Lua code */
  int co_ref;                /* registry ref of the bios coroutine; re-fetched and type-checked per resume */
  uint32_t nfn;              /* number of host functions (bounds check) */
  lua_Alloc orig_alloc; void *orig_ud;   /* LuaJIT's allocator; restored before lua_close */
  size_t used, limit;        /* bytes through the wrapper */
  cm_host_fn host_fn; void *host;        /* non-NULL only inside cm_resume */
  const unsigned char *in_spec, *in_bios; size_t in_spec_len, in_bios_len;  /* cm_load only (cpcall ud is always m, F3) */
```

### 3.6 Wire format v1

Integers are little-endian; numbers are IEEE-754 binary64. `machine.c` refuses big-endian hosts with a static assertion; Java uses `ByteOrder.LITTLE_ENDIAN`.

```
value   := 00 NIL | 01 FALSE | 02 TRUE | 03 NUMBER f64 | 04 STRING u32 len, bytes (raw Lua bytes = Latin-1)
           tags 05..0F reserved: S3 tables/back-refs/objects
request := u32 n, value*n                                       C -> Java, per host call
reply   := 00 u32 n, value*n                                    VALUES  Java -> C
         | 01 i32 level, value(NIL|STRING)                      ERROR   Java -> C
           kind 02 reserved: S5 CALLBACK
spec    := u32 napi, api*                                       Java -> C, in nLoad
api     := u32 nnames, str*nnames, u8 hasModule, [str module], u32 nmethods, method*
method  := str name, u8 flags     bit 0 = MAY_YIELD (info == null || !info.nonYielding()); other bits 0
str     := u32 len, bytes
event   := (S2) u32 n, value*n, first value = name
```

- Function indices number the methods in spec order, across all APIs, starting at 0.
- **Decoders on both sides:**
  - check every length against the remaining bytes, in `size_t` arithmetic;
  - reject unknown tags or kinds;
  - require no bytes to be left over;
  - bound the counts: `nfn` ≤ 65,536, names ≤ 256 bytes.
- The C checkers (`wire_check_reply`, `wire_check_spec`) are pure functions and never call Lua. They are the Tier 0 fuzz targets.

### 3.7 `machine.c`, function by function

**`cm_alloc(ud, ptr, osize, nsize)`** (allocator, VM thread):
- `old = ptr ? osize : 0`.
- If `nsize > old && (m->used > m->limit || nsize - old > m->limit - m->used)`, return NULL.
  - The `used > limit` guard stops `limit - used` from wrapping.
- Otherwise call `orig_alloc`. On success, or when freeing, set `used = used - old + nsize`.
- Only growth is ever refused; frees and shrinks always go through.

**`machine_of(L)`:**

```c
void *ud;
return lua_getallocf(L, &ud) == cm_alloc ? ud : NULL;
```

No Lua-visible pointer exists anywhere.

**`cm_new`** (`UNPROTECTED`):
1. `calloc` the struct.
2. `luaL_newstate()`. If it returns NULL, free the struct and return NULL.
3. `lua_atpanic(L, cm_panic)`.
4. `orig_alloc = lua_getallocf(L, &orig_ud)`.
5. `used = lua_gc(L, LUA_GCCOUNT, 0) * 1024 + lua_gc(L, LUA_GCCOUNTB, 0)` (the pattern of `allocwrap.c:32`).
6. `lua_setallocf(L, cm_alloc, m)`; set `co_ref = LUA_NOREF`, `state = CM_NEW`, `magic`.

None of these calls can raise.

`cm_panic` prints a single line to stderr, `CCLuaJIT bug: Lua error outside a protected call: <string or ?>`, then returns. Only Linux calls it; on Windows an unprotected error ends the process without it (`reports/luajit-runtime.md` §2.d).

**`cm_load`:**
1. Enter: busy CAS, magic check. Require `co_ref == LUA_NOREF`, otherwise INTERNAL.
2. Store the inputs in `m->in_*`.
3. `st = lua_cpcall(L, load_body, m)`.
4. If `st != 0`, copy the message (top of `L`, only if it is a string; otherwise `not enough memory`) into `msg`, then `lua_settop(L, 0)` and return `CM_ST_ERROR`.

**`load_body`** (`PROTECTED`; any call in it may raise). Steps in order:

1. **Open libraries** one at a time with `lua_pushcfunction(f); lua_pushstring(name); lua_call(L, 1, 0)`:
   - `""`/`luaopen_base` (this also opens `coroutine`);
   - `table`, `string`, `math`, `bit`;
   - `jit` (this is what turns the JIT on, CA-08).

   Never `luaL_openlibs`. `io`, `os`, `package`, `debug` and `ffi` are never opened.
2. **`jit.security`:** read `prng`, `strhash` and `mcode`. If any is 0, raise `CCLuaJIT: LuaJIT security defaults are off` (DESIGN.md:54).
3. **`jit.opt.start("maxmcode=256")`** (DESIGN.md:203, F11).
4. **Remove** with `lua_rawset` on explicitly pushed tables:
   - from `_G`: `jit`, `bit`, `dofile`, `loadfile`, `collectgarbage`, `gcinfo`, `newproxy`, `print`;
   - `string.dump`;
   - `_LOADED.jit` and `_LOADED["jit.opt"]`;
   - replace `registry._PRELOAD` with a new empty table.

   `_LOADED.bit` stays (decision 6).
5. **API tables:**
   - `wire_check_spec`; on failure, raise `CCLuaJIT: corrupt API table description`.
   - For each API: `lua_createtable(L, 0, nmethods)`. For each method: push the name, `lua_pushinteger(L, idx)`, `lua_pushcclosure(L, api_call, 1)`, `lua_rawset(t)`.
   - Then `rawset(_G, name, t)` for each name, and `_LOADED[module] = t` if a module is set.
   - Set `m->nfn`.
6. **Bios:** `luaL_loadbufferx(L, bios, len, "@bios.lua", "t")`. On a non-zero status, call `lua_error(L)`; the message reads `bios.lua:N: …`. Patch 03 refuses binary chunks.
7. **Coroutine:**
   - `co = lua_newthread(L)`;
   - `lua_pushvalue(L, -2)`;
   - `if (!lua_checkstack(co, 2)) luaL_error(...)`;
   - `lua_xmove(L, co, 1)`;
   - `m->co_ref = luaL_ref(L, LUA_REGISTRYINDEX)`;
   - `lua_settop(L, 0)`.

**`cm_resume`:**
1. Enter (busy CAS). If `state == CM_DEAD`, return INTERNAL `machine is dead`. If `event != NULL`, return INTERNAL `events are not implemented yet (S2)`.
2. Set `host_fn` and `host`.
3. `st = lua_cpcall(L, resume_body, m)`. If `st != 0`, the result is `CM_ST_ERROR` with the message from `L`'s top (string only), and `state = CM_DEAD`.
4. `lua_settop(L, 0)`; clear `host_fn`/`host`; release `busy`; return the result.

**`resume_body`** (`PROTECTED`):
1. `lua_settop(L, 0)`.
2. `lua_rawgeti(L, LUA_REGISTRYINDEX, co_ref)`; `co = lua_tothread(L, -1)`. If it is NULL, raise `bios coroutine missing`.
3. S2 hook point: push the event on `L`, then `lua_checkstack(co, n+1)`, then `lua_xmove`.
4. `st = lua_resume(co, 0)`.
5. Map the status:

   | `st` | Action |
   |---|---|
   | `LUA_YIELD` | `state = SUSPENDED`; `lua_settop(co, 0)`; result YIELD |
   | `0` | `state = DEAD`; result RETURNED |
   | other | `state = DEAD`; `lua_checkstack(L, 2)`; `lua_xmove(co, L, 1)`; `render_error(m, L, -1)`; result ERROR |

   S6b note: once patch 08's C-stack limit is set, `lua_resume` can return `LUA_ERRRUN` with `C stack overflow` and leave the coroutine unchanged and resumable (`lj_api.c:1273-1286`). S6b must tell that case apart from a real error instead of marking the coroutine DEAD.

**Rule for `co` outside `lua_resume`.** Only these calls are allowed:
- `lua_status`, `lua_gettop`;
- a shrinking `lua_settop`;
- `lua_type`;
- `lua_tolstring` on a `LUA_TSTRING` only;
- `lua_checkstack`;
- `lua_xmove` after `checkstack(to, n+1)`;
- `lua_resume` while `state != DEAD`.

**`render_error(m, L, idx)`** (`PROTECTED`; raw; never runs metamethods):

| Error value | Written to `msg` |
|---|---|
| string | copied as is, cut to 64 KiB |
| number | `lua_pushvalue` then `lua_tolstring` on the copy |
| nil / boolean | `nil` / `true` / `false` |
| anything else | `"%s: %08x"` of `lua_typename` and `mix32((uintptr_t)lua_topointer(L, idx) ^ id_key)` |

The last row is Cobalt's shape without an address leak (oracle: `error({})` → `table: 71248c21`).

**`api_call(L)`** (`LUA_CFUNCTION`):
- **Phase 1** (may raise):
  - `m = machine_of(L)`. Raise if `m == NULL` or `host_fn == NULL`.
  - Check that the upvalue is a number, is integral, and is below `nfn`.
  - Encode `lua_gettop(L)` values into `req_buf`:
    - strings via `lua_tolstring` on strings only;
    - `LUA_TTABLE` → `luaL_error("CCLuaJIT: tables are not supported yet")`;
    - function, thread, userdata and lightuserdata → NIL.
  - If growing the buffer fails, raise `not enough memory`.
- **Phase 2** (no Lua call): `rc = host_fn(host, idx, &req_buf, &rep_buf)`.
- **Phase 3** (may raise):
  - If `rc != 0`, raise a fixed level-0 message, for example `CCLuaJIT: Java exception in host call`.
  - Otherwise `wire_check_reply`; on failure raise `CCLuaJIT: corrupt host reply`.
  - **VALUES:** `lua_checkstack(L, n)` (on failure raise `too many results to return`), push the values, return `n`.
  - **ERROR:**
    - message is a string and `level > 0`: `luaL_where(L, level)`, push the message, `lua_concat(L, 2)`;
    - otherwise: push the message (string or nil) as is;
    - then `lua_error(L)`.
  - Level 1 from a C closure is the Lua caller's position (spike: `bios.lua:1: bad argument …`).
- **What a raise can leave behind:** only machine-owned buffers. No `malloc` block, lock, JNI frame or half-built structure is held (PLAN §5.4 item 4).

**`cm_free`:**
1. Busy CAS. If it fails, return INTERNAL and do not free; Java logs a leak.
2. `lua_setallocf(L, orig_alloc, orig_ud)`, so that `close_state` destroys the arena.
3. `lua_close(L)`. In M1 this runs no Lua code: no `newproxy`, no userdata with `__gc`, no FFI.
4. Free the buffers, set `magic = CM_DEAD`, free the struct.

```c

JNIEXPORT jlong JNICALL Java_io_github_mindbound_cclj_natives_NativeMachine_nNew(JNIEnv *env, jclass cls, jlong memLimit, jlong idKey);
JNIEXPORT jint  JNICALL Java_io_github_mindbound_cclj_natives_NativeMachine_nLoad(JNIEnv *env, jclass cls, jlong h, jbyteArray spec, jbyteArray bios);
JNIEXPORT jint  JNICALL Java_io_github_mindbound_cclj_natives_NativeMachine_nResume(JNIEnv *env, jobject self, jlong h, jbyteArray event);
JNIEXPORT jbyteArray JNICALL Java_io_github_mindbound_cclj_natives_NativeMachine_nMessage(JNIEnv *env, jclass cls, jlong h);
JNIEXPORT jint  JNICALL Java_io_github_mindbound_cclj_natives_NativeMachine_nFree(JNIEnv *env, jclass cls, jlong h);
```

The names contain no underscores, so no `_1` escapes are needed. The export check (`build-natives.sh:155-158`) and the version script (`:111`) already accept them.

- **`nAbi`** returns `CCLJ_ABI`. It is a native method, so no `JNI_OnLoad` or `FindClass` is needed.
- **`nNew`:** if `memLimit <= 0`, return 0. Otherwise `cm_new`. No JNI calls.
- **`nLoad`:**
  - `h == 0` or a null array → `CM_ST_INTERNAL`.
  - For each array: `GetArrayLength`; reject anything above `CM_WIRE_MAX`; `malloc(len ? len : 1)`; `GetByteArrayRegion`; `ExceptionCheck` (on an exception: `ExceptionClear`, free, INTERNAL).
  - Then `cm_load`, then free both copies.
- **`nResume`:**

  ```c
  typedef struct JniHost { JNIEnv *env; jobject self; jmethodID upcall; } JniHost;   /* on this stack only */
  if (h == 0) return CM_ST_INTERNAL;
  if (event != NULL) return CM_ST_INTERNAL;                         /* S2 replaces this */
  jclass cls = (*env)->GetObjectClass(env, self);
  host.upcall = (*env)->GetMethodID(env, cls, "upcall", "(I[B)[B");
  (*env)->DeleteLocalRef(env, cls);
  if (host.upcall == NULL) { (*env)->ExceptionClear(env); return CM_ST_INTERNAL; }
  host.env = env; host.self = self;
  st = cm_resume((cm_machine *)(intptr_t)h, jni_host_call, &host, NULL, 0);
  if ((*env)->ExceptionCheck(env)) { (*env)->ExceptionClear(env); st = CM_ST_INTERNAL; }   /* never return with one pending */
  return st;
  ```
- **`jni_host_call`** (`NO_LUA`; one exit label, so the frame is always popped):

  ```c
  if ((*env)->PushLocalFrame(env, 4) != 0) { (*env)->ExceptionClear(env); return CM_HOST_E_JNI; }
  jreq = NewByteArray((jsize)req->len)            NULL?            rc = E_JNI,  goto out
  SetByteArrayRegion(jreq, 0, len, req->data)     ExceptionCheck?  rc = E_JNI,  goto out
  jrep = CallObjectMethod(self, upcall, (jint)fn, jreq)
                                                  ExceptionCheck?  ExceptionDescribe; rc = E_JAVA, goto out
                                                  NULL?            rc = E_NULL, goto out
  n = GetArrayLength(jrep)                        n > CM_WIRE_MAX? rc = E_TOOBIG, goto out
  buf_reserve(rep, n)  (plain realloc)            fail?            rc = E_NOMEM, goto out
  GetByteArrayRegion(jrep, 0, n, rep->data)       ExceptionCheck?  rc = E_JNI,  goto out
  rep->len = n;
  out: if (rc == E_JNI) ExceptionClear(env);  PopLocalFrame(env, NULL);  return rc;
  ```
- **`nMessage`:** `NewByteArray` + `SetByteArrayRegion` from `cm_message`. On a failure, `ExceptionClear` and return NULL; Java shows `(no message)`.
- **`nFree`:** `cm_free`. No JNI calls.

**JNI rules (checklist):**
- J1: every JNI call that can throw is followed by `ExceptionCheck` or a NULL check before the next JNI call.
- J2: the frame is balanced through one exit.
- J3: forbidden: `FindClass`, `New*GlobalRef`, `NewStringUTF`, `GetStringUTFChars`, `Get*Critical`, `ThrowNew`.
- J4: no exception is pending at any return.
- J5: every `jsize` conversion is bounded by `CM_WIRE_MAX`.
- J6: `JNIEnv` and `self` stay on the stack of one call.

### 3.10 Java

**`natives.NativeLibrary`** (JDK-only):
- `static synchronized Path ensureLoaded(Path cacheRoot)`:
  - calls `NativeLoader.load(cacheRoot)` exactly once per JVM, then `NativeMachine.nAbi() == NativeMachine.ABI`;
  - a mismatch throws `UnsatisfiedLinkError("native ABI …")`;
  - success and failure are both sticky; a remembered failure is rethrown on every later call.
- `static boolean isLoaded()`.
- Why: `NativeLoader` does not memoise, and a second cache root would load a second copy of the library.
- A stale M0 library without `nAbi` fails with `UnsatisfiedLinkError`, which `CCLuaJITCommon` already turns into a Cobalt fallback (`CCLuaJITCommon.java:61`).

**`natives.NativeMachine`** (JDK-only, `final`):

```java
public interface Host { byte[] call(int function, byte[] request); }   // must not throw; must not keep `request`
public record Outcome(int status, String message, boolean closedWhileRunning) {}
public static final int ABI = 1;
private final Object lock = new Object();
private long handle; private boolean running, closed;              // guarded by lock
private static final AtomicInteger LIVE = new AtomicInteger();     // tests

public static NativeMachine create(Host host, long memLimit, long idKey, byte[] spec, byte[] bios)
    throws NativeMachineException   // nNew (0 -> "not enough memory"); nLoad != OK -> message, nFree, throw; any Throwable -> nFree, rethrow

public Outcome resume(byte[] event) {
  long h;
  synchronized (lock) {
    if (closed) throw new IllegalStateException("Machine has been closed");
    if (running) throw new IllegalStateException("Machine is already running");
    running = true; h = handle;
  }
  int status = ST_INTERNAL; String msg = null; long toFree = 0; boolean closedDuring = false;
  try {
    status = nResume(h, event);
    if (status != ST_YIELD) msg = Wire.latin1(nMessage(h));       // read while running is still true
  } finally {
    synchronized (lock) {
      running = false; closedDuring = closed;
      if (closed || status != ST_YIELD) { closed = true; toFree = handle; handle = 0; }
    }
    if (toFree != 0) free(toFree);                                 // outside the lock
  }
  return new Outcome(status, msg, closedDuring);
}

public void close() {                                              // any thread, any number of times
  long toFree = 0;
  synchronized (lock) {
    if (closed) return;
    closed = true;
    if (!running) { toFree = handle; handle = 0; }                 // S6a: else nInterrupt(handle, HARD)
  }
  if (toFree != 0) free(toFree);
}
private byte[] upcall(int fn, byte[] request) { return host.call(fn, request); }   // called from C only
```

`free(h)` calls `nFree`. A non-zero result logs a leak through `System.Logger`. Every free decrements `LIVE`.

**`natives.Wire`** (JDK-only):
- `decodeArgs(byte[])` returns `Object[]` of `null`, `Boolean`, `Double` and `String` (`new String(b, off, n, ISO_8859_1)`).
- `values(Object[], Consumer<Object> onUnknown)`:
  - `null`, `Boolean`, and `Number` (as `doubleValue`) map directly;
  - `String` is encoded per `char` as `c < 256 ? c : '?'` (a surrogate pair gives two `?`, as the oracle showed);
  - `byte[]` is copied verbatim;
  - `Map`, `Collection`, `Object[]` and `ByteBuffer` throw `UnsupportedValue` (until S3);
  - anything else becomes NIL and calls `onUnknown`.
- `error(String nullable, int level)`.
- `SpecWriter`.
- Every decoder throws `IllegalStateException` on malformed input.

**`computer.LuaJITMachine`:**
- **Constructor `(MachineEnvironment env, InputStream bios)`:**
  1. Read the bios. An `IOException` passes through.
  2. If `!NativeLibrary.isLoaded()`, throw `MachineException("CCLuaJIT natives are not loaded")`.
  3. Iterate `env.apis()` once. For each API, `env.luaMethods().forEachMethod(api, (target, name, method, info) -> entries.add(new Entry(target, method, name)))`. Write the spec with the names, `getModuleName()` and the `MAY_YIELD` flag. An API with no methods still gets an empty table under each of its names and in `_LOADED`, with one WARN, as Cobalt does (`CobaltLuaMachine.java:103-113`).
  4. `vm = NativeMachine.create(this::call, 64L << 20, SECURE.nextLong(), spec, biosBytes)`.
  5. Exceptions: `NativeMachineException` → `MachineException(msg)`. `RuntimeException | Error` → log at ERROR, then `MachineException("CCLuaJIT could not start: " + e)` (F15).
- **`byte[] call(int k, byte[] req)`** is total:
  - an index out of bounds gives an ERROR record at level 0;
  - `r = e.method().apply(e.target(), env.context(), new ObjectArguments(Wire.decodeArgs(req)))`;
  - `r.getCallback() != null` gives an ERROR at level 0, "… yields; not supported yet (S5)";
  - otherwise `Wire.values(r.getResult(), this::logUnknown)`;
  - `catch (LuaException x)` → `Wire.error(x.getMessage(), x.hasLevel() ? x.getLevel() : 1)`;
  - `catch (UnsupportedValue x)` → level 0;
  - `catch (Throwable t)` → log, then `Wire.error("Java Exception Thrown: " + t, 0)`.
- **`handleEvent`:**
  - name ≠ null (S1 only): `vm.checkOpen()`, `close()`, return `error("CCLuaJIT: events are not implemented yet (S2)")`;
  - otherwise map `vm.resume(null)` as in §3.12;
  - an `IllegalStateException` propagates;
  - any other `Throwable` is logged, then `close()`, then `error("CCLuaJIT internal error: " + t)`;
  - it never returns `null`.
- **`close()`:** `vm.close()`. S6a puts `removeListener` first, outside the lock (DESIGN.md:98-101).
- **`printExecutionState`:** appends `CCLuaJIT machine: <idle|running|closed>`. Pure Java; it never touches native code.

**`CCLuaJITCommon`:** `nativesAvailable()` calls `NativeLibrary.ensureLoaded(nativeCache)` instead of `NativeLoader.load`. The wrapper (`:40-42`) is otherwise unchanged; Cobalt is still used only when the natives are unavailable.

**`HeadlessRunner.factoryFor`:** for `LuaJITMachine`, call `NativeLibrary.ensureLoaded(Path.of(System.getProperty("ccluajit.nativeDir")))` first.

### 3.11 Call path: the bios calls `term.write("hi")`

1. **[Worker W1, `turnOn`, 30 s budget]** The factory runs the `LuaJITMachine` constructor.
   - The spec gives `TermAPI.write` index k, with flags 0 (`nonYielding()` is true).
   - `nNew` → `cm_new`; `nLoad` → `cm_load` → `load_body`. That builds `term.write = api_call(k)` and compiles the bios. Nothing runs.
2. **[Worker W2, may be ≠ W1]** `handleEvent(null, null)` → `vm.resume(null)`: the lock sets `running`, then `nResume(h, null)`.
3. **[W2, `jni_machine.c`]** `GetObjectClass`, `GetMethodID`, `DeleteLocalRef`, then `cm_resume(m, jni_host_call, &host, NULL, 0)`.
4. **[W2, `machine.c`]** Busy CAS → `lua_cpcall(L, resume_body, m)` → `lua_resume(co, 0)`.
5. **[W2, Lua]** `GETGLOBAL term`, `GETFIELD write`, `CALL` → `api_call`.
6. **[W2, phase 1]** `req_buf` = `01000000 04 02000000 6869` (11 bytes).
7. **[W2, phase 2]** `PushLocalFrame(4)`, `NewByteArray(11)`, `SetByteArrayRegion`, then `CallObjectMethod(self, upcall, k, jreq)`.
8. **[W2, Java]** `NativeMachine.upcall` → `LuaJITMachine.call(k, req)`:
   - the arguments decode to `{"hi"}`;
   - `LuaMethod.apply(TermAPI, ctx, ObjectArguments)` → `getStringCoerced(0)` → `TermMethods.write` → `Terminal.write` under its monitor; the cursor moves to x = 2;
   - `MethodResult.of().getResult() == null`, so the reply is `00 00000000`.
9. **[W2, phase 2]** `ExceptionCheck`, NULL check, `GetArrayLength` = 5, `GetByteArrayRegion`, `PopLocalFrame`.
10. **[W2, phase 3]** VALUES with 0 values → `return 0`.
11. **[W2, Lua]** Line 3, `error("boom")` → `bios.lua:3: boom` → `lua_resume` returns `LUA_ERRRUN`.
12. **[W2]** `resume_body`: `state = DEAD`; `checkstack(L, 2)`; `xmove(co, L, 1)`; `render_error`; result ERROR. `cm_resume` cleans up and returns 3. The `nResume` guard finds no pending exception.
13. **[W2, Java]** `nMessage` → `bios.lua:3: boom`. In `finally`: `running = false`; the result is terminal, so `handle = 0`. `nFree` runs outside the lock.
14. **[W2, CC:T]** `MachineResult.error("bios.lua:3: boom")` → `displayFailure` + `shutdown()` → `close()`, which does nothing (`ComputerExecutor.java:552-563`).

### 3.12 Outcome mapping and error paths

| Native outcome | `MachineResult` | VM afterwards |
|---|---|---|
| YIELD | `OK` | kept |
| RETURNED | `GENERIC_ERROR` (same instance) | freed |
| ERROR | `error(msg)` | freed |
| INTERNAL | `error("CCLuaJIT internal error: " + msg)`, logged at ERROR | freed |
| any outcome, with `closedWhileRunning` | `TIMEOUT` (what Cobalt reports after `close()` interrupts it) | freed |
| `cm_load` ERROR | constructor throws `MachineException(msg)`: "Error loading bios.lua"; can be retried | freed |

| Source | What Lua sees (catchable by `pcall` unless noted) |
|---|---|
| `LuaException("m")` | `bios.lua:N: m` (level 1) |
| `LuaException("m", 0)` or a negative level | `m` |
| `LuaException("m", 2)` | the caller's caller position (oracle: `bios.lua:2: lvl2`) |
| `LuaException(null)` | nil error value; rendered `nil` |
| any other `Throwable` in a method | `Java Exception Thrown: <t>` (logged) |
| `Throwable` escaping `call()` (bug or OOM) | `CCLuaJIT: Java exception in host call`; stack trace on stderr |
| null, oversized or corrupt reply | `CCLuaJIT: …` fixed text, level 0 |
| table argument (S1) | `bios.lua:N: CCLuaJIT: tables are not supported yet` |
| hitting the Lua heap cap | `not enough memory` |

### 3.13 Threads and lifecycle invariants (to review against)

- **I1:** No raising Lua call outside a `PROTECTED` body or `api_call` phases 1 and 3.
- **I2:** No Lua call during phase 2. `jni_machine.c` cannot make one (include graph).
- **I3:** No JNI exception pending when a native method returns.
- **I4:** No JNI state survives a native call: no global refs, no cached env, no static mutable data (`nm` check).
- **I5:** No Lua code runs while phase 3 reads `rep_buf`.
  - This holds because no reachable userdata has a `__gc` (no `newproxy`, no FFI, LuaJIT tables have no `__gc`).
  - Any slice that adds `__gc` userdata (M2, P14) must add a re-entrancy guard.
- **I6:** A handle is freed exactly once, by the thread that set it to 0 under the lock. The lock is never held across `nResume`, `nFree`, an upcall or a CC:T call.
- **I7:** Lua sees no C pointer. The machine is found through the allocator `ud`.
- **I8:** Each decoder checks every length.
- **Threads:**
  - Create runs on a worker. `handleEvent` runs on any worker, one at a time; `running` and `busy` enforce that anyway.
  - `close()` can come from any thread, many times.
  - `lua_close` may run on the Monitor thread when the machine is idle. That is safe, because no Lua code can run in it.
  - In S1 no `TimeoutState` listener exists, so a runaway loop wedges the worker; tests use watchdogs.
